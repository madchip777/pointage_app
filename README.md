# pointage_app

Un projet mobile FLutter, de presence.

## Espace dev :

Prerequis : 
SKD Flutter + emulateur/SKD Android studio

Lancez votre emulateur :
cd ~/[path sdk flutter]/flutter/bin$ 
flutter emulators --launch Medium_Phone_API_36.1

Et démaré la racine du projet :
lib/main.dart
